# 洞穴之咒

第一版是一层 10×10 的迷宫。扮演「只是一个普通人」，打赢守门的小 Boss 即通关。

## 环境

- [Godot 4.7 .NET](https://godotengine.org/download)（和工程里的 `Godot.NET.Sdk/4.7.2` 对齐）
- .NET 8 SDK

## 运行

用 Godot 4.7 .NET 打开本目录的 `project.godot`，再按运行。房间、门和角色是 0x72 的 CC0 地牢图，高角度能看见墙面；界面底框仍用 Kenney Pixel UI。说明在 [assets/CREDITS.md](assets/CREDITS.md)。像素图按最近邻显示。仓库里的 PNG 可以直接读；用编辑器打开后 Godot 会再生成 `.import`。

规则库不依赖引擎，可以单独测：

```bash
dotnet test tests/CaveCurse.Core.Tests.csproj
```

## 操作

- 主画面是高角度的房间，地板在地面上，墙立着。方向键或 WASD 在地板上走，走到门口再点「窥视」或「进入」。
- 右下角是小地图，不能点。走过的房间才显示类型。
- 战斗前可以换武器。窗口一打开，金色 ▶ 停在「开始战斗」上，按 J 就开战。每个按钮都标着数字，离开标着 Esc。
- 蓄力条满了按空格进入时停，可以一直不按。
- 时停里点普攻，或点左侧技能槽。没有位移按钮。切武器点左侧武器槽，不花行动点。跳过会结算。只有这时行动点还不少于 1，敌人才再停 2 秒。
- 打中会喷出一小簇方块火花，敌人死掉会碎开，并闪一下很淡的白。挥空、打中、死亡、受伤、清房、开门、捡东西都有 8-bit 音效。平时只有一层很低的背景音乐。进战斗时先响一声很短的下扫，战斗层马上进来；清房后再用约 1 秒淡出去。
- 普通剑会记住你放了几次技能。画面上方一直写着「普通剑 第几档」，后面有 `0/6` 这种进度和一排 `[##----]`。第 2 档剑身变青，挥剑多一层残影，伤害 +1。第 3 档变成发亮的青白色，伤害再 +1，并且每一刀顿帧结束后会再补一小刀。升档时屏幕闪一下青白色，中间出现「剑在回应你」，并播放一段和弦。门槛写在 `core/SwordImbue.cs` 最上面。
- 按 V 打开音量。上下移动金色高亮，左右加减，数字键 1 到 5 对应音乐、音效、减小、加大和关闭。Esc 或再按 V 也会关闭。
