- 属性名词对齐过：力量管伤害，魔力只是资源，防御是百分比减伤，冷却按秒并且只在蓄力阶段走。
- 项目需求写过，并改过两次：主画面是俯视房间，10×10 只是小地图；去掉位移；技能要从技能栏里点。
- Godot 4 + C# 工程已推到 `main`。用带 .NET 的 Godot 4.7 打开仓库根目录的 `project.godot`。
- 规则库能单独测：`dotnet test tests/CaveCurse.Core.Tests.csproj`。
- 探索：房间里用方向键或 WASD 走，走到门口再窥视或进入。右下角是小地图。
- 战斗：蓄力、空格或 J 时停、普攻、技能槽、武器槽、物品、跳过、结算后 2 秒。时停里没有「撤销」按钮；Esc 或 K 取消这一轮，已排的行动不结算。Tab 换攻击目标。时停里瞄准当前目标时，头上有「原始 → 实际」，有护盾再写「护盾 −多少」。技能槽和武器槽在战场左侧，不跟底栏按钮做成一样。
- 键盘：走路、门口、开战背包、时停、商店、事件、死亡和通关都可以不用鼠标。鼠标点按钮仍然有用。没有单独的开始菜单，一运行就在出生房。按键表在下面。
- 房间类型：战斗、商店、事件、守门小 Boss。打赢小 Boss 这一版算通关。
- 房间是高角度四分之三：地板是地面，北墙和侧墙立着，门开在墙上。人和敌人正面朝镜头。图用 0x72 DungeonTileset II（CC0）。小地图仍是右下角的平面格子。

## 玩的时候出现的问题

1. 用普通版 Godot 4.7 打开，会说缺少 `res://src/App.cs`。这是 C# 工程，必须用标题里带 .NET 的那一版，并装好 .NET 8。
2. 第一版把 10×10 格子当成了整个画面，用来点格子走路。这是错的。格子只是小地图。
3. 说明文字宽度变成一个字，竖着叠在房间左边。已改成横排，放在房间上面。要再 `git pull` 才能看到。
4. 战斗里一块黑面板盖住了人和敌人，血却在掉。已拿掉这块面板，战场改成浅色房间。白点是你，红点是敌人。
5. 时停里出现了向上、下、左、右闪避。需求里没有位移这个操作。这些按钮已删。
6. 「随机属性」被做成了一颗直接释放的按钮。它应该是技能栏里的一个技能。现在点「技能」才打开技能栏，再点「随机属性」才放。
7. 本机克隆看不到新代码，是因为没拉最新的 `main`。每次改完都要在克隆目录里 `git pull`，再用 .NET 版 Godot 重新打开。

## 按键

鼠标仍然可以点。下面这些是键盘。按钮上的 `[1]`、`[J]` 就是对应的键。当前选中的按钮是深棕色底、亮黄边框，字是浅色，前面有 `▶`。

到处都能用：

| 想做的事 | 按键 |
| --- | --- |
| 走路 | W A S D，或方向键 |
| 确认当前选中的项 | J，或回车，或空格 |
| 取消、离开 | Esc，或 K |
| 音量 | V。上下移动选中项：[1] 音乐、[2] 音效、[3] 减小、[4] 加大、[5] 关闭。左右加减当前的音乐或音效，[J] 确认，[Esc] 或再按 V 关闭 |
| 直接选第几项 | 数字键 1 到 9（和按钮上的数字一样） |
| 换到上一项 / 下一项 | 方向键，或 W A S D（只在弹出的窗口里、以及战斗时停里） |

探索，人在房间里走：

| 想做的事 | 按键 |
| --- | --- |
| 走到门口之后窥视 | 1 |
| 走到门口之后进入 | J，或回车，或空格。没按过 Tab 时，深色黄边的就是「进入」 |
| 在「窥视」和「进入」之间换 | Tab |

战斗：

| 想做的事 | 按键 |
| --- | --- |
| 蓄力满了，进入时停 | 空格，或 J，或回车 |
| 换一个要打的敌人 | Tab。被金框框住的就是目标 |
| 普攻 | 1 |
| 物品 | 2 |
| 跳过并结算 | 3。行动点用完时，选中框会自己跳到这项，再按 J 就结算 |
| 技能「随机属性」 | 4 |
| 武器槽 1、武器槽 2 | 5、6 |
| 取消这一轮时停 | Esc，或 K。已经挥过的那一刀如果还没结算，不会打中 |

开战前的背包、商店、事件、事件结果、死亡或通关后的「再来一局」：每个按钮左边有数字，当前项是深色底、黄边、浅色字，前面有 `▶`，后面写着 `[J]`。离开类按钮另外写着 `[Esc]`。方向键移动选中项，数字键直接选，[J] 确认。开战背包一打开就停在「开始战斗」上（守门时是「迎战小 Boss」），直接按 [J] 就开战；[1]、[2] 才是把当前武器放进槽。事件如果有一项叫「离开」，[Esc] 就是选它；没有「离开」的事件必须选一项。死亡和通关画面上只有「再来一局」，[J] 和 [Esc] 都是再来。

## 像素特效和声音

打中、死亡、清房这些原来就有的反馈都还在：闪白、放大、伤害数字、轻晃、约 0.08 秒顿帧、死亡时缩小变淡、清房横幅、立绘和刀光、全部键盘操作。新加的是方块粒子和 8-bit 声音。

- 打中：沿这一刀的方向喷出 6 到 10 颗小方块，白到亮黄，大约四分之一秒后直接消失。和顿帧同一下出声。
- 敌人死掉：按它衣服的主色崩出十多块，落地后再停大约 1 秒才消失。同时有一圈淡黄的像素环，从很小扩到大约 32 像素，最后两档变暗消失。画面闪一帧很淡的白。
- 最后一只死掉时，门仍按原来的节拍打开，横幅也还在。碎块要在地上停一会儿，所以回到探索会比原来的 0.42 秒稍晚，避免碎块被切掉。
- 按 V 可以调音乐和音效。

## 普通剑的浸染

这是玩法占位。人和剑开局都很普通。每真正放出一次技能（时停里排进去并且跳过结算；按 Esc 取消的不算），这把普通剑的浸染 +1。

门槛在 `core/SwordImbue.cs` 开头，只改那几个数字：

- 按每间普通战斗房大约放 2 次技能来估。一间房 2 个敌人，开局一刀大约 5 点伤害，早期敌人大约 8～12 点生命，所以大约要砍 4 刀。每次时停只有 1 点行动点，蓄力大约 8 秒，技能冷却 6 秒，下一轮技能已经好了，想升级就会在砍人之间插 2 次技能。
- 第 3 间房结束（累计 6 次）进入第 2 档。第 6 间房结束（累计 12 次）进入第 3 档。某一间少放一次，第三档会落到第 7 间。
- 开局魔力 50，一次技能 8 点，正好放 6 次升到第 2 档。再放 6 次才到第 3 档。商店里的「浑浊药水」22 金币回复 15 蓝，一间战斗大约掉 20 金币，买一两次就够。

第 2 档：剑变成青色，挥剑的刀光多一层残影，打中后伤害 +1。第 3 档：剑变成发亮的青白色，伤害再 +1，这一刀的短暂停顿结束后再补一小刀。升档时会闪一下，并出现「剑在回应你」。原来的火花、碎块、顿帧、刀光、键盘和按钮样式都还在。

时停里每次挥剑，刀光挥下的那一帧就播放对应档位的挥剑音。目标身上留一条 1 像素宽、8～12 像素长的斜斩痕：第 1 档灰白，第 2 档带青，第 3 档亮青再加一圈白边。多刀叠成交叉线，不写数字，大约每 0.3 秒轻闪一次。画面在时停里压暗偏灰。按 Esc 取消，斩痕直接消失，不炸开。结算时打中的每一刀按大约 0.06 秒的间隔各响一次命中音，音高每次高一个半音，最多高 8 个；最后一刀用更重的命中音，并带一声很短的低频。同一帧，这条斩痕散成 3～4 颗和原来一样的命中火花。时停期间音效总线低通大约 1200Hz，背景音乐降到当前的 40%；时间恢复后 0.1 秒内撤掉滤波并把音量放回去。挥空或目标已经倒下的那一刀不再补命中音，斩痕也不炸。
