# 进度与问题

记到 2026-10-12。需求以 [项目需求](/cursor/stores/self/docs/项目需求.md) 为准。程序在仓库 `main`。

## 已经完成

- 设计问答定过：俯视躲弹幕、时停排行动再结算、一个人、职业锁武器、背包、三层里第一版只做一层。
- 属性名词对齐过：力量管伤害，魔力只是资源，防御是百分比减伤，冷却按秒并且只在蓄力阶段走。
- 项目需求写过，并改过两次：主画面是俯视房间，10×10 只是小地图；去掉位移；技能要从技能栏里点。
- Godot 4 + C# 工程已推到 `main`。用带 .NET 的 Godot 4.7 打开仓库根目录的 `project.godot`。
- 规则库能单独测：`dotnet test tests/CaveCurse.Core.Tests.csproj`。
- 探索：房间里用方向键或 WASD 走，走到门口再窥视或进入。右下角是小地图。
- 战斗：蓄力、空格或 J 时停、普攻、技能槽、武器槽、物品、跳过、结算后 2 秒。时停里没有「撤销」按钮；Esc 或 K 取消这一轮，已排的行动不结算。Tab 换攻击目标。时停里瞄准当前目标时，头上有「原始 → 实际」，有护盾再写「护盾 −多少」。技能槽和武器槽在战场左侧，不跟底栏按钮做成一样。
- 键盘：走路、门口、开战背包、时停、商店、事件、死亡和通关都可以不用鼠标。鼠标点按钮仍然有用。没有单独的开始菜单，一运行就在出生房。按键表在下面。
- 房间类型：战斗、商店、事件、守门小 Boss。打赢小 Boss 这一版算通关。
- 房间是高角度四分之三：地板是地面，北墙和侧墙立着，门开在墙上。人和敌人正面朝镜头。图用 0x72 DungeonTileset II（CC0）。小地图仍是右下角的平面格子。

## 玩的时候出现的问题

1. 用普通版 Godot 4.7 打开，会说缺少 `res://src/App.cs`。这是 C# 工程，必须用标题里带 .NET 的那一版，并装好 .NET 8。
2. 第一版把 10×10 格子当成了整个画面，用来点格子走路。这是错的。格子只是小地图。
3. 说明文字宽度变成一个字，竖着叠在房间左边。已改成横排，放在房间上面。要再 `git pull` 才能看到。
4. 战斗里一块黑面板盖住了人和敌人，血却在掉。已拿掉这块面板，战场改成浅色房间。白点是你，红点是敌人。
5. 时停里出现了向上、下、左、右闪避。需求里没有位移这个操作。这些按钮已删。
6. 「随机属性」被做成了一颗直接释放的按钮。它应该是技能栏里的一个技能。现在点「技能」才打开技能栏，再点「随机属性」才放。
7. 本机克隆看不到新代码，是因为没拉最新的 `main`。每次改完都要在克隆目录里 `git pull`，再用 .NET 版 Godot 重新打开。

## 按键

鼠标仍然可以点。下面这些是键盘。按钮上的 `[1]`、`[J]` 就是对应的键。金色并且前面有 `▶` 的，是当前选中的一项。

到处都能用：

| 想做的事 | 按键 |
| --- | --- |
| 走路 | W A S D，或方向键 |
| 确认当前选中的项 | J，或回车，或空格 |
| 取消、离开 | Esc，或 K |
| 音量 | V。上下选「音乐」或「音效」，左右加减，Esc 或再按 V 关闭 |
| 直接选第几项 | 数字键 1 到 9（和按钮上的数字一样） |
| 换到上一项 / 下一项 | 方向键，或 W A S D（只在弹出的窗口里、以及战斗时停里） |

探索，人在房间里走：

| 想做的事 | 按键 |
| --- | --- |
| 走到门口之后窥视 | 1 |
| 走到门口之后进入 | J，或回车，或空格。没按过 Tab 时，金色的就是「进入」 |
| 在「窥视」和「进入」之间换 | Tab |

战斗：

| 想做的事 | 按键 |
| --- | --- |
| 蓄力满了，进入时停 | 空格，或 J，或回车 |
| 换一个要打的敌人 | Tab。被金框框住的就是目标 |
| 普攻 | 1 |
| 物品 | 2 |
| 跳过并结算 | 3。行动点用完时，金色会自己跳到这项，再按 J 就结算 |
| 技能「随机属性」 | 4 |
| 武器槽 1、武器槽 2 | 5、6 |
| 取消这一轮时停 | Esc，或 K。已经挥过的那一刀如果还没结算，不会打中 |

开战前的背包、商店、事件、死亡或通关后的「再来一局」：方向键移动金色高亮，数字键直接选，J 确认，Esc 离开。事件如果有一项叫「离开」，Esc 就是选它；没有「离开」的事件必须选一项。死亡和通关画面上只有「再来一局」，J 和 Esc 都是再来。

## 像素特效和声音

打中、死亡、清房这些原来就有的反馈都还在：闪白、放大、伤害数字、轻晃、约 0.08 秒顿帧、死亡时缩小变淡、清房横幅、立绘和刀光、全部键盘操作。新加的是方块粒子和 8-bit 声音。

- 打中：沿这一刀的方向喷出 6 到 10 颗小方块，白到亮黄，大约四分之一秒后直接消失。和顿帧同一下出声。
- 敌人死掉：按它衣服的主色崩出十多块，落地后再停大约 1 秒才消失。同时有一圈淡黄的像素环，从很小扩到大约 32 像素，最后两档变暗消失。画面闪一帧很淡的白。
- 最后一只死掉时，门仍按原来的节拍打开，横幅也还在。碎块要在地上停一会儿，所以回到探索会比原来的 0.42 秒稍晚，避免碎块被切掉。
- 按 V 可以调音乐和音效。
