# 素材

房间、门和敌人是 [0x72](https://0x72.itch.io/dungeontileset-ii) 的 16x16 DungeonTileset II。高角度能看见墙面和正面的人，不是正上方，也不是菱形等距。许可是 CC0，可以商用，署名不强制。

玩家是 `dungeon/player.png`：32×32，透明底，棕发、暖棕色衣服、银剑，轮廓有一圈深色边，默认朝右。向左走时游戏会把这张图左右翻转。

界面底框仍用 [Kenney](https://kenney.nl) 的 Pixel UI。没有中文字形，文字仍用系统里的中文字体。

| 包 | 用在哪里 | 许可 |
| --- | --- | --- |
| 0x72 DungeonTileset II | 地板、立起来的砖墙、墙上的门；吐弹的守卫、向前冲的小怪、守门 | `dungeon/License.txt`，来源 https://0x72.itch.io/dungeontileset-ii |
| 玩家 `dungeon/player.png` | 探索和战斗里的玩家。32×32，朝右，向左镜像 | 本仓库自带 |
| Kenney Pixel UI Pack | 顶栏、弹窗和按钮的九宫格 | `kenney/pixel-ui/License.txt` |

子弹和小地图仍是纯色。Kenney Tiny Dungeon 和 Monster Builder 还留在仓库里，房间和怪物已经不用它们。
